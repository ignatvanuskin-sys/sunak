# СТО «Сунақ» — сайт с системой онлайн-записи

Готовый коммерческий сайт для автосервиса **«Сунақ»** (Астана, ул. Озбекали Жанибек, 30Б).
Статический лендинг: чистый HTML + CSS + JS, без сборки и зависимостей.

---

## 1. Что внутри

```
index.html                    — весь лендинг (семантическая разметка, SEO, Schema.org)
robots.txt
assets/
  css/styles.css              — дизайн-система и адаптив
  js/app.js                   — мастер записи, календарь, галерея, меню, модальные окна
  favicon.svg
  img/opt/                    — оптимизированные фотографии (.webp + .jpg)
api/
  booking.example.js          — пример backend-обработчика заявок (Telegram-уведомление)
_data/                        — рабочие материалы исследования (в репозиторий идут только json/txt/py)
  originals/                  — исходные фото из 2ГИС (локально, в .gitignore)
  reviews_p1.json, reviews_p2.json, reviews_readable.txt
  parse_reviews.py, prepare_images.py
```

Локальные артефакты, которые **не** коммитятся (см. `.gitignore`):
`_qa/`, `_qa2/` — скриншоты и измерения QA-прогонов, `_ref/` — разбор сайта-референса
Yasira Motors (скриншоты + выгрузки computed-стилей), `qa-*.js` — отладочные скрипты.

## 2. Как открыть

Локально (рекомендуется — так работают все ссылки и карта):

```bash
cd "путь/к/сунак"
python -m http.server 8080
# открыть http://127.0.0.1:8080
```

Либо просто открыть `index.html` в браузере — вся вёрстка и мастер записи работают,
но встроенная карта может не загрузиться из-за ограничений `file://`.

## 3. Система записи: как она работает сейчас

Форма записи собрана как мастер из 4 шагов: **услуга → дата → время → контакты**.
Есть валидация, маска телефона `+7 XXX XXX XX XX`, состояния загрузки/ошибки/успеха,
сохранение черновика в `sessionStorage` и экран успеха со сводкой заявки.

Отправка работает в одном из двух режимов — переключается одной строкой в `assets/js/app.js`:

| Режим | Что происходит | Как включить |
|---|---|---|
| **WhatsApp** (включён по умолчанию) | Заявка собирается в готовое сообщение и передаётся в WhatsApp компании. Никаких «фальшивых» подтверждений: интерфейс прямо говорит пользователю, что осталось отправить сообщение. | ничего делать не нужно |
| **Backend** | Заявка уходит POST-запросом (JSON) на ваш API, администратор получает уведомление. | указать `BOOKING_CONFIG.endpoint` |

### Включение реального backend

1. Скопируйте `api/booking.example.js` в свой проект как `api/booking.js`
   (Vercel Functions / Netlify Functions / любой Node-хостинг).
2. Задайте переменные окружения:
   `TELEGRAM_BOT_TOKEN` (бот от @BotFather) и `TELEGRAM_CHAT_ID` (id администратора или группы).
3. В `assets/js/app.js` укажите:

```js
var BOOKING_CONFIG = {
  endpoint: '/api/booking',
  whatsapp: '77753375793',
  phone: '+77753375793',
  business: 'СТО «Сунақ»'
};
```

После этого заявка уходит на сервер, а администратор получает сообщение вида:

```
Новая запись — СТО «Сунақ»

Имя: Иван
Телефон: +7 775 337 57 93
Услуга: Аргонная сварка
Дата: 2026-10-12
Время: 14:30
Комментарий: корпус КПП, нужна сварка
```

Payload, который отправляет форма:
`name`, `phone`, `service`, `date`, `time`, `comment`, `source`, `createdAt`.

## 5. Дизайн (переработан под референс)

Сайт полностью пересобран в стилистике референса `yasira-motors.vercel.app` — тёмный
индустриальный премиум. Тексты авторские, данные «Сунақ», акцент — фирменный, а не
красный из референса: у «Сунақ» вывеска сделана жёлтым по тёмному, так что жёлтый
на графите — буквально их бренд (видно на фото фасада и вывески внутри цеха).

**Основа системы:**

| Элемент | Решение |
|---|---|
| Фон | near-black `#08090B`, «поднятые» секции `#0E1013`, карточки `#14171B`, чипсы `#191D22` |
| Границы | hairline 1px (`#242A31`) — вместо теней, только одна тень у главной кнопки |
| Акцент | жёлтый `#FFC400`, hover `#FFD333`, текст на жёлтом `#12100A` |
| Заголовки | Oswald 600, uppercase, tracking −0.012em; H1 до 80px, третья строка — контурная (`-webkit-text-stroke`) |
| Текст | Manrope 16px / 1.62 |
| Лейблы | JetBrains Mono 11px, uppercase, tracking 0.22em |
| Радиусы | карточки 10px, кнопки 7px, чипсы 4px |
| Атмосфера | зерно (inline SVG-шум, opacity .035), жёлтый радиальный спотлайт в hero, бегущая строка услуг |

**Структура страницы:** фиксированная шапка → hero на `100svh` с фото на 58% ширины
и полосой фактов внизу (Город / Профиль / Адрес / Связь) → бегущая строка → **«Что
беспокоит?»** (10 кнопок-симптомов, открывают запись с уже выбранной услугой) → услуги
единым списком с hairline-разделителями вместо карточек → «Четыре причины» + бейдж
2ГИС → «Как мы работаем» (4 шага 01–04) → bento-галерея → о компании → отзывы слайдером
с индикатором «Отзыв N из 10» → FAQ → контакты в 2 колонки с картой → финальный CTA
с анимированными лучами → футер.

Ключевые приёмы взяты у референса осознанно: hairline вместо карточек-теней, mono-лейблы,
контурная строка в H1, список услуг вместо сетки, симптом-селектор как главный сценарий
входа, индикатор слайдера. Своё: акцентный цвет, контент, композиция hero под портретные
фото, сохранённая система онлайн-записи (в референсе её нет вообще).

### Тонкие места при правках (проверено на практике)

- **`[hidden]` и авторский `display`.** В reset стоит `[hidden]{display:none !important}`:
  без него `.btn{display:inline-flex}` перебивает браузерное правило, и в мастере записи
  одновременно показываются все три кнопки.
- **Базовый `display:none` нужно сбрасывать в медиазапросе.** У `.nav` базовое `display:none`,
  поэтому в мобильном медиазапросе явно задан `display:flex` — иначе меню «открывается», но невидимо.
- **Не ставить `white-space:nowrap` на кнопки.** Длинные подписи вылезают за экран на 320–360px.
  Плюс `min-width:0` у флекс/грид-детей и `minmax(0,1fr)` в треках.
- **Проверять `color` кнопки против фона родителя.** «Призрачная» кнопка, рассчитанная на тёмный
  фон и вставленная в светлую секцию, становится белым на белом.
- **Один токен цвета на два фона ломает контраст.** Для мелкого текста нужны отдельные
  переменные: `--fog-500` (на тёмном) и `--fog-400` (на светлом).
- **`--bar-h` + 2px в `padding-bottom` у `body`.** Фиксированная панель выше на 1px из-за
  `border-top`; без запаса копирайт в футере на 390px заходит под панель на 1px.
- **H1 в hero рассчитан ровно на 3 строки.** При увеличении `font-size` или уменьшении
  `max-width` у `.hero__content` строка «Ремонт двигателя, ГБЦ» начнёт переноситься и hero
  перестанет помещаться в один экран.

**Анимации:** fade-up при скролле с каскадом 70 мс, hover-переходы (карточки — смена
границы и фона, фото — `scale(1.035)`), плавные модальные окна и лайтбокс, бегущая
строка, «лучи» в финальном CTA. Параллакса нет. Всё отключается через `prefers-reduced-motion`.

## 7. SEO и доступность

- `<title>`, `meta description`, Open Graph, favicon, `robots.txt`;
- один `H1`, корректная иерархия заголовков, `alt` у всех изображений;
- JSON-LD `AutoRepair` с адресом, координатами, графиком, телефоном, способами оплаты
  и `aggregateRating` (4,8 / 151) — данные реальные;
- семантические `header/nav/main/section/footer`, `fieldset`/`legend` в форме,
  `aria-label`, `aria-modal`, `role="alert"` для ошибок, скрытые подписи;
- видимый фокус (жёлтый контур), skip-link, ловушка фокуса в модальных окнах,
  закрытие по Esc, поддержка клавиатуры в галерее.

**`og:url` и `og:image`** уже прописаны абсолютными адресами на текущий деплой
(`https://sunak-five.vercel.app/`) — превью ссылки в WhatsApp и Telegram показывает
фото сварки из цеха. Когда появится свой домен, замените их на него и добавьте
`<link rel="canonical">` и `sitemap.xml`.

## 9. Что стоит сделать дальше

1. **Получить реальный прайс-лист** у владельца — тогда блок «Цены» превратится
   в полноценную таблицу услуг с ценами (структура уже готова).
2. **Подключить backend** (`api/booking.example.js`) — чтобы заявки приходили
   в Telegram, а не только в WhatsApp.
3. **Уточнить гарантию и марки авто** — как только будут подтверждены, их можно
   добавить в блок преимуществ и FAQ.
4. **Подтвердить фото** — сейчас на сайте 8 реальных фото из 2ГИС (с водяным знаком
   2ГИС в углу). Для коммерческого запуска лучше заказать собственную фотосессию:
   фасад, цех, станки, процесс сварки.
5. **Разобраться с негативными отзывами.** В 2ГИС у компании 44 отзыва на 5★ и
   17 отзывов на 1★; почти все негативные — про токаря и про расхождение цены
   «по телефону и на месте». На сайте показаны реальные отзывы и реальный средний
   рейтинг, но владельцу стоит ответить на критику — это влияет на конверсию сильнее,
   чем любой редизайн.
6. **Домен и хостинг** — сайт статический, подойдёт любой (Vercel, Netlify, обычный
   хостинг). Достаточно загрузить файлы `index.html`, `robots.txt`, `assets/`.
